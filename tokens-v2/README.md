# tokens-v2 (Vitae 27)

New token set for the Vitae 27 library. Built alongside the current `tokens/` folder, which stays in place and keeps the live Storybook working until v2 replaces it.

- `primitives.json` — Phase 1, signed off 10/16/26. Raw values only, no meaning: one cool neutral ramp (010–220), brand ramps for EA, DC, MA and ME (005–190, with 100 as each client's brand color), status ramps, metal and program colors, spacing, radius, border widths, type sizes, line heights, weights, families, motion and two elevations.
- Mirrors the **Primitives** collection in the [Vitae 27](https://www.figma.com/design/FgVdwGszfnY0vz75yxfJ7F) Figma file. Figma code syntax uses `var(--vitae-<path>)`, for example `var(--vitae-color-dc-primary-100)`.
- `brand/{ea,dc,ma,me}.json`: Phase 2, signed off 10/16/26. Brand roles per client: the three ramps as `brand.*`, brand-tinted light-mode text, the dark-mode button picks, font family and radius. Phase 3 (Button, 10/16/26) added outline/ghost text colors per client and mode, the dark hover/pressed tints, and moved dark solid buttons to near-white fills (primary 010, secondary and tertiary 020). Mirrors the **Brand** collection (modes EA, DC, MA, ME) in Figma.
- `semantic/{light,dark}.json`: Phase 2, signed off 10/16/26. 81 color roles (background, field, border, text, icon, action, support). Phase 3 added 20 outline/ghost button roles (`action.*-text*`, `action.*-subtle-*`), borders for every alert (`support.*-border`), and for Input (10/16/26) `field.border-active` and `field.background-active`, with `field.border` and `field.border-hover` now pointing at per-client blends (`brand.light|dark.field-border*`: 20% and 60% of the way from the grey rest border to the active border). Mirrors the **Color** collection (modes Light, Dark). Pick one brand file and one semantic file to get any of the 8 combinations.
- Text styles (26) live in Figma, with the font family bound to `brand/font/family`: headings H1–H6 and Dialog; Body (Regular, Bold, Label, Button, Input, Helper); table; navigation (Breadcrumb, Breadcrumb Current, Filter Heading); **Link** (Link/Body, Link/Body Hover, Link/Label, Link/Small, Link/Small Hover — renamed 10/20/26 from Body/Link, Body/Link Hover, Body/Label Link and Navigation/Breadcrumb Hover; the underline is part of each style, so always apply the Link style rather than underlining text by hand); and **Label** (Label/Badge 12/16 for count badges, Label/Tagline 12/16 Bold for the drawer tagline). Body/Input is 16/20 (text inside fields); Body/Helper is 14/20 (helper and error text).

- Program tags (10/20/26): `color.program.*-dark` and `*-dark-surface` primitives added for Healthy DC Plan (DC) and Clear Choice Plan (ME); semantic `program.dc-healthy-*` and `program.me-clear-choice-*` roles in both light and dark. Use only in the matching client.
- Tier 4 navigation (10/20/26):
  - Brand: `brand.light|dark.nav-*` (accent, rule, bar, admin-bar, admin-text), `brand.dark.nav-drawer`, `brand.light|dark.footer-*` (bg, lang-bg, pill) and `brand.light|dark.progress-upcoming`. Dark nav bars use DC secondary 170 and EA/MA/ME primary 150.
  - Semantic: `nav.*` (accent, rule, bar, admin-bar, admin-text, bar-text, badge, badge-text, drawer, item-hover, item-pressed, item-selected, panel), `footer.*` and `progress.upcoming` (always used at 40% opacity; gray for DC).
  - Boolean switches (`$type: boolean`, not part of DTCG; map them to a CSS class or data attribute): `logo.show-color` / `logo.show-white` (semantic: color logo in light, all-white in dark) and `progress.connector-gapped`, `progress.connector-continuous`, `progress.current-center-dot` (brand: EA/MA/ME use gapped connectors, DC continuous; all use an open ring for the current step).
  - Components that use them: Header, Footer and mobile drawer; Breadcrumbs; Pagination; Left nav (2px hover bar at 40%, 4px selected bar); Mobile nav toggle (shared by Left nav and Progress); Progress and Progress line (Ends=Rounded on desktop, Flush under the mobile toggle); Tabs (underline, horizontal scroll on mobile).
- Components bind every color, spacing (`space.*`), radius (`radius.*`, `brand.radius.*`), border width (`border-width.*`), shadow (Elevation styles) and text style to a token (audited 10/20/26). Exceptions: client logo artwork, and fixed element sizes such as 44px rows.

Status surfaces use step 015 of each status ramp (decided 10/16/26).
